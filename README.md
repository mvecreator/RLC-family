# Общая электрическая теория семьи

## Аннотация

В настоящей работе предлагается минимальная электротехническая модель семейной системы на основе пассивного RLC-контура.

В рамках модели принимается следующая идентификация:

$$
\boxed{
\text{мужчина}=C,\qquad
\text{женщина}=L,\qquad
\text{ребёнок}=R
}
$$

где $C$ — ёмкость, $L$ — индуктивность, $R$ — сопротивление.

Показано, что мужчина способен накапливать потенциал, женщина определяет фазовую динамику системы, а дети создают сопротивление независимо от выбранной топологии соединения.

Полученные результаты позволяют сформулировать условия семейного резонанса, определить режимы короткого замыкания и предложить физическую интерпретацию развода как разрыва цепи.

## Быстрый старт: используйте репозиторий прямо из своей LLM

Для работы с RLC-family **не требуется отдельное веб-приложение**.

Рекомендуемый интерфейс — обычный чат с LLM, которой доступен этот репозиторий и Python.

Пользователь просто описывает ситуацию человеческим языком:

> У нас двое детей, один подросток. Ипотека 1450 в месяц, общий доход около 5000. В последнее время напряжение выше среднего, но разговариваем нормально. После беседы с подругой жена обычно успокаивается.

Дальше LLM должна:

```text
прочитать описание семьи
→ выделить факты
→ явно показать качественные допущения
→ собрать FamilyScenario
→ передать его детерминированному Python-solver
→ получить AnalogIR и численный результат
→ перевести результат обратно в семейный язык
```

Таким образом репозиторий сам является **LLM-ready рабочим окружением**:

```text
LLM = естественно-языковой интерфейс
Python = расчётное ядро
RLC-family repo = каноническая модель и протокол
```

### Что нужно от LLM

Для полного режима модель должна уметь:

1. читать файлы этого репозитория;
2. следовать [CHAT_INTERFACE.md](CHAT_INTERFACE.md);
3. запускать `python3` или иной эквивалентный способ исполнения solver;
4. не подменять численный результат собственной литературной интерпретацией.

Если LLM не умеет запускать код, она всё ещё может подготовить `FamilyScenario`, но расчёт следует выполнить отдельно через:

```bash
python3 simulator/rlc_family_sim.py scenario.json --out out/run
```

## 1. Основные положения

Рассмотрим замкнутую семейную цепь.

В простейшем случае она содержит три базовых элемента:

$$
C,\quad L,\quad R.
$$

Назовём их соответственно:

- мужской ёмкостью;
- женской индуктивностью;
- детским сопротивлением.

Таким образом, семья представляет собой RLC-систему с переменными параметрами.

### Аксиома 1. Мужчина обладает ёмкостью

Мужчина моделируется элементом $C$.

Физически ёмкость характеризует способность системы накапливать заряд:

$$
Q=CU.
$$

В семейной интерпретации это означает, что мужчина способен длительное время накапливать потенциал, не обязательно демонстрируя его окружающим.

При превышении допустимого напряжения возможен пробой.

### Аксиома 2. Ребёнок оказывает сопротивление

Ребёнок моделируется активным сопротивлением $R$.

Для него выполняется закон:

$$
U=IR.
$$

Следовательно, чем выше сопротивление ребёнка, тем больше напряжение необходимо приложить для достижения требуемого тока.

Из этого непосредственно следует известный экспериментальный факт:

> просьба одеться с первого раза не является стационарным режимом.

При наличии нескольких детей эквивалентное сопротивление зависит от способа их включения.

При последовательном соединении:

$$
R_{\Sigma}=R_1+R_2+\ldots+R_n.
$$

Таким образом, последовательное увеличение числа детей приводит к линейному росту общего сопротивления.

При параллельном соединении:

$$
\frac1{R_{\Sigma}}
=
\frac1{R_1}
+
\frac1{R_2}
+\ldots+
\frac1{R_n}.
$$

Однако экспериментальная семейная практика показывает, что воспользоваться этим эффектом удаётся редко.

### Аксиома 3. Женщина сдвигает фазу

Женщина моделируется индуктивностью $L$.

Для идеальной индуктивности выполняется:

$$
U_L=L\frac{dI}{dt}.
$$

Индуктивный элемент сопротивляется быстрому изменению тока и изменяет фазовые отношения между током и напряжением.

Следовательно:

$$
\boxed{\text{женщина сдвигает фазу}}
$$

что одновременно является физическим свойством элемента модели и бытовым описанием состояния системы.

## 2. Почему женщины последовательно-параллельны

Рассмотрим исходный вопрос:

> Почему женщины последовательно-параллельны?

Ответ определяется структурой семейной цепи.

Мужчины обладают ёмкостью, дети оказывают сопротивление, женщины создают индуктивную составляющую.

Следовательно, семейная система может быть соединена последовательно, параллельно либо по более сложной топологии.

При этом ключевые свойства элементов сохраняются.

Отсюда фундаментальное следствие:

$$
\boxed{
\text{как ни подключай — сопротивление остаётся}
}
$$

Однако фазовое состояние системы может измениться.

---

## 3. Полное семейное сопротивление

Для последовательного RLC-контура комплексное сопротивление имеет вид:

$$
Z
=
R
+
j\left(
\omega L-\frac1{\omega C}
\right).
$$

В семейной интерпретации:

$$
\boxed{
Z_{\text{семьи}}
=
R_{\text{детей}}
+
j
\left(
\omega L_{\text{женщины}}
-
\frac1{\omega C_{\text{мужчины}}}
\right)
}
$$

Первая часть выражения описывает реальные потери энергии.

Вторая характеризует реактивную составляющую семейных отношений.

Следовательно, семейное сопротивление имеет две принципиально различные природы:

1. реальное сопротивление;
2. мнимая составляющая.

Практические наблюдения показывают, что различить их в бытовых условиях бывает затруднительно.

---

## 4. Семейный резонанс

Резонанс наступает при выполнении условия:

$$
\omega L=\frac1{\omega C}.
$$

Тогда реактивные составляющие компенсируются:

$$
\omega L-\frac1{\omega C}=0.
$$

Следовательно:

$$
Z=R.
$$

В семейной интерпретации это означает:

> мужская ёмкость полностью компенсирует женскую индуктивность.

Система входит в состояние гармонии.

Однако детское сопротивление при этом не исчезает.

Таким образом, даже идеально подобранная пара не обеспечивает нулевого полного сопротивления семейной системы.

---

## 5. Собственная частота семьи

Резонансная частота определяется выражением:

$$
\omega_0=\frac1{\sqrt{LC}}.
$$

Следовательно:

$$
\boxed{
\omega_{\text{семьи}}
=
\frac1{\sqrt{
L_{\text{женщины}}
C_{\text{мужчины}}
}}
}
$$

Каждая семейная пара обладает собственной характерной частотой.

Если внешнее воздействие происходит с частотой, близкой к $\omega_0$, амплитуда процессов внутри семьи может резко увеличиваться.

Примерами внешнего периодического воздействия являются:

- ремонт;
- отпуск;
- приезд родственников;
- ипотечный платёж;
- вопрос «ты меня вообще слушаешь?».

---

## 6. Фазовый сдвиг

Для реактивной системы ток и напряжение не обязаны совпадать по фазе.

Угол фазового сдвига определяется:

$$
\varphi
=
\arctan
\frac{
\omega L-\frac1{\omega C}
}{R}.
$$

При

$$
\varphi>0
$$

семья имеет преимущественно индуктивный характер.

При

$$
\varphi<0
$$

преобладает ёмкостной характер.

При

$$
\varphi=0
$$

наблюдается резонанс.

В бытовом приближении:

$$
\varphi\neq0
$$

означает, что один участник разговора уже отвечает на вопрос, который другой ещё не успел задать.

---

## 7. Добротность брака

Для последовательного RLC-контура добротность определяется выражением:

$$
Q
=
\frac{\omega_0 L}{R}.
$$

Следовательно, условная семейная добротность:

$$
Q_{\text{семьи}}
=
\frac{
\omega_0 L_{\text{женщины}}
}{
R_{\text{детей}}
}.
$$

Чем меньше сопротивление и выше реактивность системы, тем выраженнее резонансные процессы.

Слишком высокая добротность нежелательна, поскольку даже слабое внешнее воздействие может вызвать значительную амплитуду колебаний.

Иными словами:

> хорошая семья должна быть достаточно добротной, но не настолько, чтобы её разносило от одного импульса.

---

## 8. Переходные процессы

После любого резкого изменения условий семейная система не мгновенно приходит в новое состояние.

Возникает переходный процесс.

Его причинами могут быть:

- свадьба;
- рождение ребёнка;
- переезд;
- потеря пульта;
- покупка мебели;
- появление второго ребёнка после уверенности, что с первым всё уже понятно.

В общем случае процесс описывается дифференциальным уравнением второго порядка:

$$
L\frac{d^2q}{dt^2}
+
R\frac{dq}{dt}
+
\frac{q}{C}
=
E(t).
$$

Таким образом, семейная жизнь в минимальном приближении является системой второго порядка с внешним возбуждением.

## 9. Короткое замыкание

Если сопротивление системы становится близким к нулю при достаточно высоком напряжении, ток резко возрастает.

Такой режим назовём семейным коротким замыканием.

Характерный признак:

$$
I\rightarrow\infty.
$$

В реальной семье бесконечный ток недостижим, поскольку раньше срабатывает защита.

В качестве защитных устройств могут выступать:

- уход в другую комнату;
- прогулка;
- звонок другу;
- внезапная необходимость вынести мусор.

---

## 10. Разрыв цепи

При разводе цепь становится разомкнутой.

Для идеального разрыва:

$$
R\rightarrow\infty,
\qquad
I\rightarrow0.
$$

Ток между элементами прекращается.

Однако энергия, ранее накопленная в реактивных элементах, может сохраняться некоторое время.

Для конденсатора:

$$
E_C=\frac{CU^2}{2}.
$$

Для катушки:

$$
E_L=\frac{LI^2}{2}.
$$

Поэтому после физического разрыва цепи переходные процессы могут продолжаться.

Особенно при наличии общего сопротивления.

## 11. Теорема о детском сопротивлении

**Теорема.**

В любой практически реализуемой семейной цепи, содержащей хотя бы одного ребёнка, существует ненулевая сопротивляющаяся компонента.

**Доказательство.**

Пусть ребёнок характеризуется сопротивлением

$$
R>0.
$$

При последовательном соединении сопротивление непосредственно входит в $Z$.

При параллельном соединении его вклад входит в общую проводимость.

Следовательно, изменение топологии не устраняет сам факт существования $R$.

Что и требовалось доказать.

## 12. Основной закон семейной электротехники

На основании рассмотренной модели можно сформулировать основной закон:

$$
\boxed{
\text{мужчины — ёмкости,}
\quad
\text{дети — сопротивление,}
\quad
\text{женщины сдвигают фазу}
}
$$

Отсюда следует главный практический вывод:

$$
\boxed{
\text{как ни подключай — схема всё равно семейная}
}
$$

## Заключение

Предложенная RLC-модель показывает, что основные семейные процессы могут быть формально описаны средствами классической электротехники при условии полного отказа от здравого смысла.

Модель объясняет:

- накопление потенциала;
- сопротивление;
- фазовый сдвиг;
- резонанс;
- переходные процессы;
- короткие замыкания;
- разрыв цепи.

Дальнейшее развитие теории должно включать изучение:

- тёщи как внешнего источника ЭДС;
- любовника как паразитной связи;
- бывших партнёров как остаточного заряда;
- семейного бюджета как закона сохранения энергии;
- подростка как нелинейного элемента;
- домашних животных как шумового источника;
- брачного договора как устройства токовой защиты.

Вход задаётся семейными терминами. Скрипт компилирует их во внутренний `AnalogIR`, строит нормализованную аналоговую RLC/RLCM-схему и финансово-оптическую подсистему, выполняет расчёт и затем переводит результат обратно в семейный язык.

Артефакты одного запуска:

- `analog_ir.json` — внутренняя аналоговая схема;
- `circuit.net` — pseudo-SPICE представление;
- `result.json` — численный результат;
- `report.md` — семейная интерпретация.

Регрессионные тесты:

```bash
python3 -m unittest discover -s tests -v
```

## Решение задач по запросу

**[HARMONY1 — Query-driven equation and harmonization engine](HARMONY_ENGINE.md)**

Чат теперь может не только описывать текущее состояние, но и формулировать конкретную задачу:

```text
семейное описание + вопрос
→ ProblemSpec
→ выбор нужной системы уравнений
→ детерминированное решение
→ сравнение сценариев
→ семейная интерпретация
```

Поддержаны:

- общая диагностика;
- расчёт резонансной частоты;
- точка финансовой безубыточности;
- допустимая ипотечная нагрузка;
- требуемый резерв;
- `what-if` перерасчёты;
- поиск стабилизирующих изменений `harmonize`.

Пример:

```bash
python3 simulator/problem_solver.py \
  examples/family_scenario.json \
  examples/problem_harmonize.json
```

Важно: численные показатели гармонизации — это внутренние инженерные метрики RLC-family, а не измерение реального счастья, психического здоровья или качества семьи.

## SIM-TIME1 — динамика во времени

**[SIM-TIME1 — Event-driven time-domain family model](TIME_ENGINE.md)**

Теперь RLC-family умеет считать не только один статический режим, но и последовательность событий во времени:

```text
семейная история по дням
→ TimelineSpec
→ система дифференциальных уравнений
→ RK4-интегрирование
→ временные ряды
→ семейная интерпретация
```

Пример:

```bash
python3 simulator/time_solver.py \
  examples/family_scenario.json \
  examples/family_timeline.json \
  --out out/time-demo
```

Динамическое состояние включает заряд/ток RLC-контура, память, финансовый резерв и ипотечный долг. События могут временно менять параметры системы или создавать дискретные импульсы денег/памяти.

Пользователь по-прежнему не обязан писать JSON: LLM должна компилировать TimelineSpec из обычного рассказа и показывать принятые допущения.

## Scenario Lab — проверка модели ситуациями

**[Scenario Lab](SCENARIO_LAB.md)**

RLC-family развивается не только добавлением новых формул. Для модели создан постоянный сценарный стенд:

```text
придумать бытовую ситуацию
→ задать ожидаемое качественное направление
→ прогнать SIM-TIME1
→ найти нелепости
→ исправить уравнения
→ закрепить эффект regression-тестом
```

Первый цикл уже выявил и исправил три проблемы:

1. плохая коммуникация случайно получала премию за электрическое демпфирование;
2. подростковая нелинейность могла выглядеть стабилизирующей только из-за роста R;
3. финансовая подсистема считалась параллельно, но не влияла обратно на семейную динамику.

Запуск текущего sanity-набора:

```bash
python3 simulator/scenario_lab.py
python3 -m unittest discover -s tests -v
```

## PERSON2 — следующий архитектурный слой

**[PERSON2 — смешанная RLC-модель персонажей](PERSON_MODEL.md)**

Следующий переход не расширяет старую формулу исключениями. Каждый взрослый и ребёнок становится собственным смешанным RLC-узлом, а каналы между людьми моделируются отдельно.

Пол/гендер остаётся только опциональным слабым legacy-prior исходной шутки; фактические роли, возраст и индивидуальный temperament должны иметь больший вес. Перед включением PERSON2 предусмотрен отдельный `PERSON-CAL`.

## PERSON2 / PERSON-NET1 — семья как сеть персонажей

**[PERSON2 — смешанная RLC-модель персонажей](PERSON_MODEL.md)**  
**[PERSON-CAL](PERSON_CALIBRATION.md)**

Теперь каждый взрослый и ребёнок может быть отдельным смешанным `R || C || L`-узлом. Фактические роли и temperament меняют C/L-профиль; gender label используется только как слабый опциональный legacy-prior.

Комплексный узловой решатель:

```bash
python3 simulator/person_network_solver.py \
  examples/person_family_scenario.json \
  --out out/person-net
```

PERSON-NET1 решает матрицу проводимостей и возвращает напряжение/фазу каждого персонажа, ток каждого канала и сетевые сводные показатели. В чатовых запросах для этого используется `ProblemSpec = {"type":"person_network"}`.


**[PERSON-NET1 — узловой решатель сети персонажей](PERSON_NETWORK.md)**

PERSON-NET1 решает `Y V = I` для отдельных RLC-персонажей и считает фазу каждого узла и ток каждого канала связи. Большой ток канала означает сильный обмен, а не автоматически конфликт.
