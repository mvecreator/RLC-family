# CALIB1 — семейные калибровочные тесты

CALIB1 — следующий уровень после Scenario Lab.

Scenario Lab ищет странности свободными бытовыми историями.  
CALIB1 фиксирует **парные контрольные ситуации** с заранее указанным направлением эффекта и числовым допуском.

Это калибровка **внутренней RLC-family модели**, а не калибровка на реальных семейных данных.

## Принцип

Каждый тест меняет один главный фактор при максимально одинаковых остальных условиях:

```text
A — контроль
B — изменённый фактор
→ SIM-TIME1
→ сравнение численных траекторий
→ PASS / FAIL
```

Если тест падает, нельзя исправлять только текст интерпретации. Нужно проверять уравнения.

## Что CALIB1 уже обнаружил

### Недостаточный внешний сброс

До CALIB1 разница между слабым и сильным согласованным внешним сбросом была почти нулевой:

```text
final memory:
weak dump   ≈ 0.2544
strong dump ≈ 0.2539
```

Причина: релаксация шла почти только через

```text
P_rad = i² R_rad
```

при небольшом токе.

Исправление:

```text
support_relaxation
  ∝ dump
  * matching
  * memory
```

После калибровки:

```text
weak dump   ≈ 0.2368
strong dump ≈ 0.2272
```

То есть согласованный внешний канал теперь способен реально разгружать состояние памяти даже без большого электрического тока.

### Полезный отрицательный контроль

CAL08 специально не требует, чтобы любое улучшение финансов увеличивало «гармонию».

Если семья уже имеет:

```text
financial_stress = 0
```

то дополнительная премия:

```text
+5000 reserve
```

не меняет relationship-memory в текущем окне.

Это защищает модель от ложного принципа:

> «больше денег автоматически лечит всё».
